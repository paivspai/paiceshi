# 派总电商利润监控表 V2.2

这是一个使用 HTML、CSS、JavaScript 制作的中文电商利润测算工具。可在浏览器打开 `index.html`，无需额外服务或 API Key。

## 功能
- 输入 3–5 款 SKU 的售价、销量、商品成本、包材、快递，自动汇总 GMV。
- 输入广告支出、退款率、退款额外货损、税费、管理费、平台费、人工及场地固定成本。
- 输出预计净利润、综合 ROI 和当前销量规模下的保本 ROI。
- 自动保存在浏览器本地，支持每天清零销售与广告支出。

## 计算口径
- `GMV = Σ(单价 × 数量)`
- `留存收入 = GMV × (1 - 退款率)`
- `商品成本 = Σ(数量 × (1 - 退款率) × 单件裸成本)`
- `履约成本 = Σ(数量 × (单件包材 + 单件快递))`
- `额外退货损耗 = 总件数 × 退款率 × 每笔退款额外货损`
- `预计净利润 = 留存收入 - 商品成本 - 履约成本 - 额外退货损耗 - 留存收入 × (税率+管理费率+平台费率) - 广告消耗 - 当日固定成本`
- `综合ROI = GMV / 广告消耗`（广告消耗为 0 时不展示）
- `保本ROI = GMV / (广告前贡献利润 - 当日固定成本)`（分母不大于 0 时无法保本）

**假设与限制：** 所有 SKU 用统一退款率、每件视作一笔退款订单，退款商品的裸成本可回收；费率按留存收入估算。此为经营情景测算，不是财务结算系统，不应作为税务或投资决策的唯一依据。

## 使用方法
1. 打开 `index.html`。
2. 输入 SKU 实付单价及数量；输入对应成本。
3. 根据实际运营填写广告、退款及固定费用。
4. 看预计利润和保本 ROI，调整参数模拟经营情景。
